## 📂 Project Modules

### 1. 🏠 Main Portfolio (`index.html`)
The landing page that connects all projects.
* **Live Crypto Widget:** Fetches real-time prices for BTC, ETH, SOL, and TON via the CoinGecko API.
* **Theme Switcher:** Global Light/Dark mode toggle that saves your preference in `localStorage`.
* **Responsive Design:** Fully optimized for desktop and mobile devices.

### 2. 👟 Sneakers Shop (`shop.html` & `cart.html`)
A fully functional e-commerce simulation without a backend.
* **Shopping Cart Logic:** Add items, prevent duplicates, and track quantities.
* **Persistence:** Uses `localStorage` to save cart contents — items remain even after refreshing the page.
* **Dynamic Calculations:** Automatic total price updates and "Checkout" simulation.
* **Size Selector:** Users can choose specific shoe sizes before adding to the cart.

### 3. 🔍 Google Clone (`google.html`)
A visual replica of the Google search engine.
* **UI/UX:** Accurate recreation of the layout and styling.
* **Search Functionality:** Redirects real queries to Google search.

### 4. 🟢 Matrix Effect (`matrix.html`)
A visual experiment using the HTML5 `<canvas>` element.
* **Digital Rain:** Classic "Matrix" falling code effect using Japanese Katakana and Latin characters.
* **Performance:** Optimized rendering loop using `requestAnimationFrame`.

### 5. 📬 Contact System (`contacts.html`)
* **Formspree Integration:** Functional contact form that sends emails directly to me using AJAX (fetch API).
* **Feedback UI:** Dynamic button states ("Sending...", "Success", "Error").

* **Core:** HTML5, CSS3, JavaScript (ES6+).
* **Styling:** Flexbox, CSS Grid, CSS Variables, Keyframe Animations (`goldPulse`, `jump`).
* **Data Handling:** Browser `localStorage`, JSON parsing.
* **APIs:** * **CoinGecko API** (Crypto prices).
